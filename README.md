# gpx-editor

Currently in development (not functional)

Edits ``.gpx``, ``.kmz`` & ``.kml`` files for you

It allows you to edit the length of the track in time.

This allows you to specify a time interval for each recorded coordinate.


The ``--start-time`` flag for specifying the starting time

The ``--end-time`` flag for specifying the ending time

The ``--interval`` flag (``-i``) for specifying the interval between the points in the map
